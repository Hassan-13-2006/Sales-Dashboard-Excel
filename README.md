# 📊 Sales Dashboard in Excel

An interactive Sales Dashboard built using Microsoft Excel to analyze sales performance, profitability, orders, and product performance.

## 🎯 Project Overview

This project uses a dataset of 500 sales orders from 2026 and transforms the raw data into an interactive business dashboard.

The dashboard allows users to analyze sales performance by region, category, state, product, and month.

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Conditional Formatting
- Excel Formulas
- Data Analysis

## 📈 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Monthly Sales Trend
- Sales by Category
- Profit by Region
- Sales by State
- Top 10 Products by Sales
- Region filter
- Category filter

## 📊 Dataset

- Total Orders: 500
- Year: 2026
- Regions: North, South, East, West
- Multiple product categories and states
- Sales, Cost and Profit metrics

## 🔎 Interactivity

The dashboard includes interactive slicers for:

- Region
- Category

Selecting a slicer automatically updates the charts and KPI cards.
